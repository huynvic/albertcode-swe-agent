# Reproducing a result

Every published result can be checked at one of two levels.

1. **Check the scoring.** Each report includes the harness's own output and the per-task outcomes.
   Run the benchmark's official harness on the published outputs and confirm that you get the same
   count.
2. **Re-run it.** Install the AlbertCode version named in the report, connect the same model with the
   same settings, and run the same task list as the report describes. Model output varies between
   runs, so expect the count to vary a little. Tell us if yours differs by more than that.

Reproduced a result, or couldn't? Open an issue with the **Benchmark** label, and include your run
date, setup and outcomes. An independent reproduction can make a result **independently verified**.

# Roadmap

What we're working on next. The priorities change with what users report. Open an
[issue](https://github.com/huynvic/albertcode-swe-agent/issues) or start a
[discussion](https://github.com/huynvic/albertcode-swe-agent/discussions) to make the case for
something.

## Now

- **First public release.** Installers for Windows, macOS and Linux, with checksums, on the
  releases page.
- **A recorded demo** of a real session, replacing the illustrative one in the README.

## Next

- **Signed installers**, so that Windows SmartScreen and macOS Gatekeeper don't warn.
- **Package managers:** winget on Windows and Homebrew on macOS.
- **`albertcode --version`**, and a built-in update check that you can switch off.
- **Published benchmark results**, following the [benchmark methodology](benchmarks/README.md).

## Later

- More example commands, agents and integration guides, contributed by the community.
- Guides for running AlbertCode in CI.

Nothing here is a promise of a date. Finished items move to the [changelog](CHANGELOG.md).

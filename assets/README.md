# Brand assets

| File | Use |
|---|---|
| `logo/mark.svg` | The mark on dark backgrounds (GitHub dark mode, terminals, social) |
| `logo/mark-light.svg` | The mark on light backgrounds |
| `logo/glyph.svg` | The mark without its tile; takes the surrounding text colour |
| `logo/favicon-32.png`, `logo/icon-180.png`, `logo/icon-512.png` | Favicon, touch icon, app icon |
| `social/social-preview.png` | The repository's social preview, 1280×640 |
| `demo/albertcode-demo.gif` | The README walkthrough (illustrative) |

The mark is an **A** drawn as a caret, with a terminal cursor as its crossbar.

| Colour | Hex |
|---|---|
| Ink | `#0D1117` |
| Paper | `#F4F6F8` |
| Signal green (on dark) | `#3DDC97` |
| Signal green (on light) | `#12A26B` |

Leave the mark unaltered: don't recolour, stretch or outline it, and keep clear space of at least a
quarter of its width around it.
